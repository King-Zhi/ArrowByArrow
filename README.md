# 《一箭又一箭》益智解谜小游戏 (Arrow by Arrow)

> 软件工程课程个人作业（第二次）—— 基于 Python + Pygame 与 AIGC 协同开发的一款休闲解谜点击消除游戏。

---

## 一、项目简介

《一箭又一箭》是一款以空间拓扑与逻辑推演为核心的网格解谜游戏。在网格棋盘中分布着指向不同方向（上、下、左、右）的箭头，玩家需要观察箭头之间的相对阻挡关系，找出当前前方无阻挡的箭头并依次点击消除，直到棋盘上所有箭头全部清空。

若点击的箭头在前进路线上被其他箭头阻挡，则箭头会发生受阻晃动，并扣减一次失误机会；失误机会耗尽则游戏失败。游戏考验玩家的全局观察能力与逆向推理思维。

---

## 二、功能特性

- **核心点箭头消除机制**：
  - 支持 **上 (UP)、下 (DOWN)、左 (LEFT)、右 (RIGHT)** 四个正交方向。
  - **射线投射路径检测算法**：精确判断同一行或同一列上是否存在阻挡物。
  - **边界安全防护**：棋盘边缘朝外的箭头可安全飞出，杜绝数组越界。
- **丰富的动画与视听反馈**：
  - **飞出动画**：平滑加速飞离视口，并附带动态彩色粒子溅射。
  - **碰撞反馈**：指数衰减正弦晃动动画与红色警示粒子。
  - **程序合成音效系统**：无需外部音频资源文件，通过波形数学合成纯正 16-bit PCM 音效（飞出、碰撞、通关和弦、失败提示）。
- **完善的关卡系统**：
  - 内置 4 个难度递进的精心设计关卡（从 4x4 新手关卡到 6x6 终极箭阵）。
  - **拓扑求解器保障**：所有关卡均经过自动求解器验证，100% 确保存在合法通关解。
  - 关卡选择菜单，支持自由切换关卡挑战。
- **高分附加功能 (Bonus Features)**：
  - **智能提示 (Hint)**：自动寻找当前可消除箭头并以金色光环动态呼吸高亮。
  - **悔棋撤销 (Undo)**：支持单步撤销已消除箭头及失误惩罚。
  - **AI 自动求解演示 (Auto Solve)**：一键开启 AI 自动推演，动态演示通关全流程。
  - **用时与星级评价**：关卡通关后根据失误次数计算 1~3 星评级。

## 三、开发与运行环境

- **操作系统**：Windows 10 / 11 / macOS / Linux
- **编程语言**：Python 3.8 ~ 3.13+
- **图形与音频库**：`pygame-ce` (>=2.5.0)

## 四、安装与启动指南

### 1. 克隆或下载本仓库
```bash
git clone <您的仓库链接>
cd 软工作业二
```

### 2. 安装依赖库
建议在终端或命令提示符中执行：
```bash
pip install -r requirements.txt
```

### 3. 启动游戏
```bash
python main.py
```

### 4. 运行自动化测试
```bash
python -m unittest discover -s tests
```

## 五、操作说明与快捷键

| 操作 / 快捷键 | 功能说明 |
|:---|:---|
| **鼠标左键** | 点击选择棋盘中的箭头，或点击界面按钮 |
| **快捷键 R** | **重新开始**当前关卡（恢复初始布局与生命次数） |
| **快捷键 H** | **智能提示**（金色动态光环高亮一枚可行箭头） |
| **快捷键 U** | **撤销上一步**（恢复消除箭头或失误次数） |
| **快捷键 A** | 开启 / 暂停 **AI 自动演示求解** |
| **快捷键 ESC** | 返回主菜单 / 关卡选择 |

## 六、游戏界面展示

本游戏包含完整的现代化图形交互界面，运行 `python main.py` 即可畅玩：
- **开始主界面**：包含精致暗色主题标题、开始挑战、关卡选择、音效开关与退出按钮。
- **游戏棋盘与消除过程**：直观展示二维正交箭阵，点击支持平滑飞出与粒子特效，遇阻呈现物理阻尼震颤反馈。
- **智能提示与 AI 演示**：呼吸发光光环动态高亮可行箭头，支持一键全自动拓扑推演演示。
- **关卡通关与失败结算**：包含用时统计、失误记录及 1~3 星评级结算弹窗。
